# SimSpace

> SimSpace Corporation builds a realistic, high-fidelity cyber range and simulation platform used by security teams to train people, test technology, and train, validate and operationalize AI agents alongside human defenders. Products include the AI Proving Grounds, Range Workbench and Team Trainer, delivered through the SimSpace Portal Suite. Headquartered in Orlando, Florida.

This file is generated by API Evangelist from the public SimSpace surface. It is not published by SimSpace.

## What is machine-readable today

SimSpace describes its platform as API-first, and its own release notes reference an audit-log extraction endpoint and a bulk REST API service. The platform API answers on https://portal.simspace.com/api/v1, but its reference documentation is served only from the authenticated portal single-page application and a customer-only Freshdesk support site. **No public OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf or WSDL contract was found on any SimSpace host.**

What SimSpace does serve anonymously is an OAuth-protected Model Context Protocol endpoint on its corporate site, discoverable through RFC 8414 and RFC 9728 metadata.

## APIs

- [SimSpace Platform API](https://portal.simspace.com/): base https://portal.simspace.com/api/v1 — live, undocumented publicly, customer-only reference
